            Accuretta / manual 01
            
Your model.
Your machine.

            
Short answers about running local models, approvals, memory, tools, and the parts that can still bite.

          

          
        


        


        

          
01
Essentials
What the app is and how a session behaves.

          

            

              What is Accuretta?
              
Accuretta is a local-first interface and tool harness for models served by llama.cpp. The core app runs on your computer at localhost:8787. It does not require an Accuretta account or a cloud model.

            

            

              What are Auto, Agent, and IDE modes?
              
Auto chooses a suitable route from your request. Agent lets the model use enabled tools for files, commands, research, and other work. IDE is aimed at building and previewing web interfaces. Your access mode still controls which actions need approval.

            

            

              Where are chats and settings stored?
              
Accuretta keeps its working data under the local data directory, including chats, settings, summaries, memories, and local usage counters. Deleting a chat removes that chat from the app, while aggregate usage totals may remain.

            

          

        


        

          
02
Models & images
The model supplies the brain. The harness supplies the hands.

          

            

              Can any GGUF model use tools?
              
Tool quality depends on the model and its chat template. Models that emit standard tool calls use the native path. Some models use text-shaped function calls, which Accuretta can parse through its compatibility path. A model can still be too small, badly quantized, or poorly trained for reliable agent work.

            

            

              Can a text-only model understand an attached image?
              
No. Image display and model vision are separate abilities. The chat can show an attachment, but the model needs compatible vision support and a loaded projector to inspect its pixels. Printing text such as <preview> or running a Python script does not magically create vision.

            

            

              What does the vision projector setting do?
              
A matching mmproj file connects a supported multimodal model to image input. Off keeps the model text-only, Auto looks for a compatible projector beside the model, and Manual uses the exact projector you choose. A mismatched projector can fail or produce nonsense.

            

            

              How do I fit a large MoE model into limited VRAM?
              
Use Settings → Auto-tune and set a realistic VRAM budget. Accuretta reads the model metadata and proposes context size, GPU layers, cache precision, batching, and CPU expert offload. Treat the estimate as a strong starting point, then verify real speed and memory use on your machine.

            

            

              What happens beyond a model's native context limit?
              
Accuretta can enable YaRN scaling when the configured context exceeds the limit recorded in the model. This can provide more working space, but it does not retrain the model. Recall, precision, and attention to early details may gradually degrade, and the amount varies by model. Treat extended context as useful extra room rather than guaranteed native-quality memory.

            

          

        


        

          
03
Memory
How long sessions stay useful without eating the whole context window.

          

            

              What does the context ring show?
              
It estimates how much of the loaded model's context window the current prompt uses. The ring is a safety gauge, not a perfect tokenizer reading, so it intentionally leans conservative.

            

            

              What happens when a chat becomes too long?
              
Accuretta compacts older completed turns into a structured rolling summary. The current system keeps the original request, recent user instructions, and exact identifiers such as paths, URLs, issue IDs, and hashes as separate continuity evidence. The full chat remains stored; the model receives the compacted working version.

            

            

              Does compaction make the model smarter?
              
It gives the same model a cleaner memory. That improves recall in long sessions and reduces the amount of old text sent during compaction. It does not change the model weights, increase the physical context limit, or rescue a weak model from poor reasoning.

            

            

              What is long-term memory?
              
Long-term memories are small durable notes saved across chats, such as a preference, command, or project fact. Review and remove them in Settings. They are useful context, not sacred scripture, so delete stale or incorrect entries.

            

          

        


        

          
04
Safety & privacy
Local-first still requires a steering wheel and brakes.

          

            

              What do Soft, Medium, and Hard approval modes mean?
              
Soft allows routine low-risk actions. Medium also trusts normal writes inside the workspace. Hard asks for every action. Raw commands, tests, deletions, program launches, desktop control, and protected operations keep stricter gates. Some destructive actions are refused outright.

            

            

              Can keyboard shortcuts approve protected actions?
              
No. A shortcut may approve the newest ordinary request, but protected actions still require the hold-to-approve control. This prevents an accidental keypress from changing sensitive parts of the system.

            

            

              Does anything leave my computer?
              
Core chat inference and local counters stay on this machine. Data can leave when you deliberately use web tools, allow external preview resources, connect GitHub, enable Discord, pair a remote machine, or ask an agent to contact an online service. Those features are optional and should be treated as network access.

            

            

              Are usage stats telemetry?
              
They are local aggregate counters used by the Usage Stats page. Accuretta records performance totals and model health without storing prompt or reply content in the model comparison dataset. The page does not require sending those counters to a remote analytics service.

            

          

        


        

          
05
Workflow
Small conveniences that prevent repetitive finger gymnastics.

          

            

              Can I bind my own keyboard shortcuts?
              
Yes. Open Settings → Keyboard shortcuts, choose an action, and press the combination you want. Shortcuts can approve or deny the newest request, open pages, create a chat, focus the composer, or stop generation. Use Delete or Backspace while recording to clear a binding.

            

            

              What keyboard controls are built in?
              
Enter sends from the composer, Shift+Enter adds a line, and Ctrl+K or ⌘K opens the session switcher. Escape closes full pages and overlays. Custom shortcuts are added in Settings.

            

            

              Does the composer keep drafts?
              
Yes. Draft text is saved per chat in browser storage and restored when you return. Sending the message clears that chat's draft.

            

            

              Can I use Accuretta from another device?
              
The local server can be reached from your LAN using the inference computer's address. Tailscale support can provide private remote access across your tailnet. Secure browser features may require the HTTPS address created by Tailscale Serve.

            

          

        


        

          
06
Troubleshooting
Common failures, translated from machine grunting.

          

            

              Why did the model produce no visible answer?
              
A reasoning model can spend its reply budget thinking and run out before it reaches the answer. Raise the reply or thinking budget, use a lower effort, or choose a model that follows the expected reasoning template more reliably.

            

            

              Why is the first turn after compaction slower?
              
Compaction changes the prompt prefix, so the server may need to rebuild its fast attention cache for the new condensed history. Later turns can reuse that prefix again. The pause is real, but it buys room for the session to continue.

            

            

              Why did a tool fail even though the chat still works?
              
A tool can fail because of permissions, a missing program, network trouble, invalid arguments, or a rejected approval. That usually means the individual action failed, not that Accuretta itself crashed. Read the short error, fix the cause, and retry only that action.

      Red team stealth
    

    

      anti-fingerprinting for the recon HTTP tools: per-request rotating browser User-Agents and browser-like headers (no app name; no machine identifiers are ever sent). optional proxy routes red-team HTTP through Burp / Tor / a VPN gateway so your real IP never touches the target; XFF spoof seeds target logs with random source IPs; jitter randomizes request timing. TLS fingerprint stays python-native — for a real browser fingerprint, use the playwright MCP browser.
